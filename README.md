## SmartHire — multi-tenant HR, payroll and collaboration SaaS

The deepest piece of engineering I have built, and a private repository. The short version:

- **12-service TypeScript backend** — 11 domain services behind an API gateway handling routing,
  central JWT verification, correlation IDs, circuit breaking and WebSocket proxying.
- **46 screens** — 31 tenant pages (attendance calendar, payroll runs with month-level ledger
  locking, kanban, real-time chat, form builder, billing) plus a 15-page operator admin panel.
- **Security work I am proud of** — found and closed cross-tenant write vulnerabilities, moved bank
  details, IBAN, salary and TOTP secrets to AES-256-GCM encryption at rest, and made admin scopes
  fail closed to least privilege.
- **444 automated assertions** — 35 Playwright E2E tests across desktop and mobile, plus 409
  Postman/Newman API assertions covering RBAC, tenant isolation and cent-exact payroll formulas.
- **Live-verified integrations** — Stripe (subscriptions, true recurring MRR, dunning), Resend,
  Cloudinary and Cloudflare Turnstile, each proven end to end against the real provider.

`Node.js` `Express` `TypeScript` `Prisma` `PostgreSQL` `Redis` `BullMQ` `Socket.io` `Next.js` `Docker`
